# 移轴镜头焦平面实验室（Tilt-Shift Lab）

摄影课程教学工具：直观展示移轴镜头倾斜后焦平面（Scheimpflug 原理）与景深楔形如何变化。
纯前端，无后端；场景保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm test         # 模型核验测试（vitest）
npm run build    # 生产构建
npm run check    # svelte-check 类型检查
```

## 技术栈

- **Svelte + TypeScript**：焦距 f、光圈 N、倾角 θ、对焦距离 u、弥散圈 c 的参数面板与读数；
- **Three.js**：3D 场景——传感器、镜头、清晰焦平面（目标平面）、景深近/远界面、铰链线、Scheimpflug 线；
- **mathjs**：薄透镜近轴模型求解（透镜方程求值、平面交线线性方程组 `lusolve`、单位换算 `unit`）；
- **IndexedDB**：本地保存/载入场景；
- **SVG 二维剖面**：与 3D 场景共用同一 Svelte store，参数变化即时同步。

## 模型（明确假设）

坐标：镜头中心为原点，z 沿相机光轴（被摄体在 z<0），传感器在 z=s′ 且垂直于光轴，镜头绕竖直轴（y）倾斜 θ。

- 像距：`s′ = f·u / (u·cosθ − f)`（θ=0 退化为 `f·u/(u−f)`）；
- 清晰焦平面（物方）：`z = −u − (u·sinθ/f)·x`，过铰链点 `H=(−f/sinθ, 0)` 与 Scheimpflug 点 S（镜头平面 ∩ 传感器平面），即**三平面共线**；
- 焦平面倾角：`tanψ = (u/f)·sinθ`；
- 景深：像方焦深容差 `±N·c`（c 为用户给定弥散圈直径）映射为物方过铰链线的两个平面（景深楔形）；`z_i·cosθ ≤ f` 时远端延伸至无穷远；
- **普通平行焦面（|θ|≈0）与 Scheimpflug 情形分别处理**，平行模式退化为标准超焦距公式。

### 简化假设（导出文件中同样注明）

1. 薄透镜：镜头零厚度，主面重合；
2. 近轴（高斯）光学：忽略像差、畸变、渐晕；
3. 仅 tilt（绕竖直轴），不含 swing/shift 效应；
4. 景深完全由用户给定的 CoC 经几何光学推出，**不渲染任何"看起来清晰"的材质**；
5. 忽略衍射与像素采样；
6. 3D 视图中传感器/镜头为示意尺寸。

### 奇异与越界处理（停止给出精确结果）

- `u·cosθ ≤ f`：无法成实像（奇异几何）；
- `|θ| > 45°`：超出薄透镜近轴模型适用范围；
- `|θ| > 15°`：近轴精度下降，仅警告；
- `N·c/f ≥ 1`：焦深公差过大，近端面退化为前焦平面（警告）；
- 非法输入（非正焦距/光圈/CoC/物距）。

## 核验（`src/lib/optics.test.ts`）

- **零倾角回归**：平行模式景深与标准超焦距公式 `D_n=u(H−f)/(H+u−2f)`、`D_f=u(H−f)/(H−u)` 一致；
- **已知平面**：三平面共线（焦平面过 S）、铰链规则 `J=f/sinθ`（焦平面与景深界面均过 H）、焦平面过 `(0,−u)` 且斜率 `−(u/f)sinθ`；
- **对焦距离**：沿镜头法线 `1/d_o + 1/d_i = 1/f`；
- **单位切换**：mm/m 输入同一物理场景结果一致（mathjs `unit` 换算互逆）；
- **连续性**：θ→0 时 Scheimpflug 结果收敛到平行模式；
- **越界**：上述奇异情形均判定 `valid=false` 且不输出平面。
